# Ashveil: Пепел

3D сюжетная история (глава 1) на Godot 4.7.

## Сюжет главы 1
Ты очнулся у костра в мире Ashveil. Поговори с Ирой, почини рацию,
найди медальон, открой северные ворота.

## Управление
- **Телефон:** джойстик, кнопки ПРЫЖОК / ДЕЙСТВИЕ, свайп справа — камера
- **ПК:** WASD, свайп/drag справа, E — действие, Space — прыжок

## Сборка
Пуш в `main` → GitHub Actions собирает debug-APK и создаёт релиз.
