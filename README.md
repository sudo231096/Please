# Scraplands

Выживание от первого лица в духе Rust: пустошь, добыча еды, дикие звери.

## Что есть
- Вид от первого лица (мышь/свайп — обзор, WASD — ходьба)
- Выживание: голод и жажда падают, нужно есть и пить
- Hotbar инвентаря (6 слотов) + отдельный экран инвентаря с иконками
- Добыча: деревья (в т.ч. большие), камни, сера (валуны), железо, металл
- Крафт и строительство (стены, фундамент, дверь, костёр, печь, верстак) — всё доступно сразу
- Животные: курица, олень, кабан, крупный медведь (скачанные 3D-модели)
- Холмистый ландшафт как в Rust + карта мира (кнопка «КАРТА»)
- Случайный спавн + гарантированные ресурсы рядом
- Сенсорное управление на телефоне

## Управление
- WASD — ходьба · мышь — обзор · ЛКМ — удар · Space — прыжок · E — есть · Q — пить
- На телефоне: джойстик слева, свайп справа — обзор, кнопки справа
- Меню: «Играть» справа внизу, «Настройки» слева вверху (чувствительность, сторона кнопок)

## Сборка
Godot 4.7.1 (GL Compatibility), Android export через GitHub Actions.
