# Skibidi Toilet Survival

3D-игра: ты — камерамен, дерёшься кулаками со скибиди-туалетами на городских улицах (вид от третьего лица сверху).

## Фичи
- Полное управление камераменом (во все стороны)
- Отдельные уровни, сложность и длина растут
- Монеты, магазин прокачки урона и HP
- Виртуальный джойстик + кнопка удара на телефоне

## Управление
- WASD / стрелки — движение во все стороны
- Space / J / ЛКМ — удар кулаком
- На телефоне: джойстик слева, кнопка «УДАР» справа

## Сборка
Godot 4.7.1 (GL Compatibility), Android export через GitHub Actions.
