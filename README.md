# Scraplands

Игра-выживание от первого лица в духе Rust: ты в пустоши, отбиваешься от диких зверей.

## Что есть
- Вид от первого лица (мышь/свайп — обзор, WASD — ходьба)
- Топор: удар по ближайшим врагам
- Дикие звери (медведи) преследуют и атакуют, бесконечно возрождаются
- Пустошь: деревья, камни, сухая трава, солнце
- HP, счётчик убийств
- Сенсорное управление на телефоне (джойстик + прыжок + удар)

## Управление
- WASD — ходьба · мышь — обзор · ЛКМ — удар · Space — прыжок
- На телефоне: джойстик слева, свайп справа — обзор, кнопки справа

## Сборка
Godot 4.7.1 (GL Compatibility), Android export через GitHub Actions.
