# Skibidi Toilet Survival

3D-игра: ты — камерамен, отбиваешься от волн скибиди-туалетов (вид от третьего лица сверху).

## Фичи
- Волны врагов, сложность растёт
- Автоприцел на ближайшего скибиди-туалета
- HP, очки, рекорд (сохраняется)
- Виртуальный джойстик + кнопка огня на телефоне

## Управление
- WASD / стрелки — движение
- Space / J / ЛКМ — стрельба
- На телефоне: джойстик слева, кнопка «ОГОНЬ» справа

## Сборка
Godot 4.7.1 (GL Compatibility), Android export через GitHub Actions.
